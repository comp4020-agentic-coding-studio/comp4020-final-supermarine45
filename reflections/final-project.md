# Reflections

1. What was the breakthrough that moved the work forward?
As I was finishing up the project, I realized that my project lacked coherence. Though tt fulfilled the premise as a productivity tool, with pomodoro timer, the multi-user features (e.g., voting) were not very well thought-off. As such, in the last weeks of the project, I decided to rescope the project, by redesigning how the user interacts with the app (i.e., the process flow). Only then was I able to appropriately design the features intentionally and the work could move forward.

2. What did this work change about who I want to be as a software developer?
The project highlighted the importance to have intentions while designing a system. It is not sufficient to have a system which fulfills criteria on paper alone, as it will results in poor user experience. In this case, poorly thought initial design resulted in an app that is confusing for the users. I would like to, therefore, be a more intentional software develooper, which always plan ahead and carefully consider all features/user base when building a system.
