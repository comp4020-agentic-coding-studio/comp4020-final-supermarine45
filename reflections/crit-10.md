# Reflections

1. What was the breakthrough that moved the work forward?
The main hurdle in this week's crit is implementing proper logging. Once this have been done, I could proceed to decide which user behaviours to log. In my case, I decided to start by implementing simple user logging (e.g., user entering/leaving a session), before moving to log specific behaviours of the users (e.g., voting behaviours).

2. What did this work change about who I want to be as a software developer?
This crit highlighted the importance of proper user activity logging in software systems. As developers, we can sometimes overlook seemingly minor features such as logging in favour of more visible functionality. However, it is important to take a holistic approach to software development, considering not only the user-facing features but also the underlying systems that support them. Subsequently, I want to become a developer who looks beyond the immediate requirements and considers how seemingly small features, such as logging, contribute to the system’s overall functionality, and long-term reliability.
