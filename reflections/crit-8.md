# Reflections

1. What was the breakthrough that moved the work forward?
Initially, I intended on implementing a broad set of features. The breakthrough came when I decided to scope the project down to a lightweight system with a focused set of essential features only. This also ensures that each component of the prototype has a clear purpose, as emphasized in the assignment brief. 

2. What did this work change about who I want to be as a software developer?
I realized the importance of properly scoping a development project. It is more effective to develop iteratively and add features as necessary, rather than attempting to implement and ship large changes all at once. This is particularly important when working within an agentic framework, as I found that the agent (i.e., Claude) performed instructions more effectively when tasks were broken down into smaller, well-defined pieces.
